===============================================================================
XAMPP Setup for midterm.local - Quick Instructions
===============================================================================

STEP 1: Configure Apache Virtual Host
----------------------------------------
1. Open XAMPP Control Panel
2. Click "Config" button next to Apache
3. Select "httpd-vhosts.conf"
4. Copy and paste the content from "midterm.local-vhost.conf" file
   OR manually add this at the end:

   <VirtualHost *:80>
       ServerName midterm.local
       DocumentRoot "C:/xampp/htdocs/MidTerm230100575/public"
       <Directory "C:/xampp/htdocs/MidTerm230100575/public">
           Options Indexes FollowSymLinks
           AllowOverride All
           Require all granted
       </Directory>
   </VirtualHost>

STEP 2: Edit Windows Hosts File
---------------------------------
1. Open Notepad as Administrator:
   - Right-click Notepad → "Run as administrator"
   - Or search "Notepad" in Start menu → Right-click → "Run as administrator"

2. Open file: C:\Windows\System32\drivers\etc\hosts

3. Add this line at the end:
   127.0.0.1    midterm.local

4. Save the file (Ctrl+S)

STEP 3: Restart Apache
-----------------------
1. In XAMPP Control Panel
2. Click "Stop" for Apache
3. Wait a few seconds
4. Click "Start" for Apache

STEP 4: Test
------------
Open your browser and visit:
   http://midterm.local/

You should see your Laravel application!

===============================================================================
TROUBLESHOOTING
===============================================================================

If you get "403 Forbidden":
- Check the DocumentRoot path in httpd-vhosts.conf matches your actual path
- Make sure it points to the "public" folder, not the root folder

If you get "This site can't be reached":
- Verify hosts file was saved correctly
- Make sure you saved it as Administrator
- Try: Open CMD as Admin → type: ipconfig /flushdns

If the virtual host doesn't work:
- Make sure httpd-vhosts.conf is included in httpd.conf
- In XAMPP, click Apache Config → httpd.conf
- Look for: Include conf/extra/httpd-vhosts.conf
- Make sure it's NOT commented out (no # at the start)
